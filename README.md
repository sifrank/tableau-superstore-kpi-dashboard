# Superstore KPI Dashboard

An interactive Tableau dashboard built to explore business performance using the Superstore dataset.

## Live Dashboard

[View the interactive dashboard on Tableau Public](https://public.tableau.com/app/profile/samantha.frank4175/viz/SuperstoreKPIDashboard_17833944874370/SuperstoreDashboard)

## Project Overview

This project presents Superstore data in an interactive KPI-focused dashboard. It is designed to make business performance easier to explore through visual reporting and interactive analysis.

The dashboard is published on Tableau Public so viewers can interact with the report online.
