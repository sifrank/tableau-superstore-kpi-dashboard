# Superstore KPI Dashboard

An interactive Tableau dashboard for exploring retail sales performance, profitability, and business trends using the Superstore dataset.

**[View the interactive dashboard on Tableau Public](https://public.tableau.com/app/profile/samantha.frank4175/viz/SuperstoreKPIDashboard_17833944874370/SuperstoreDashboard)**

## Project Overview

This project uses Tableau to turn the Superstore dataset into an interactive business intelligence dashboard. The goal is to make key performance patterns easier to identify and investigate through KPI-focused visualizations.

Rather than presenting the data as a static set of charts, the dashboard provides an at-a-glance view of business performance and supports further exploration of the underlying sales data. It demonstrates dashboard design, visual analysis, and the communication of business information to both technical and non-technical audiences.

## Business Questions

The dashboard is designed to support questions such as:

- How is overall sales performance trending?
- How does profitability compare across products and business segments?
- Which product categories or areas contribute most to sales and profit?
- Where might performance differences or opportunities for improvement exist?
- How can users move from high-level KPIs to more detailed views of business performance?

## Dashboard Features

- **KPI-focused reporting:** Presents key performance indicators in a consolidated view.
- **Interactive analysis:** Allows users to explore the data directly in Tableau Public.
- **Comparative views:** Helps examine differences in performance across relevant business dimensions.
- **Visual storytelling:** Uses charts and dashboard layout to make patterns, comparisons, and potential areas of interest easier to understand.

## Tools & Skills Demonstrated

- **Tableau:** Dashboard development, chart design, and interactive data visualization
- **Tableau Public:** Publishing and sharing an interactive dashboard
- **Business intelligence:** KPI-oriented reporting and performance analysis
- **Data analysis:** Exploring sales and profitability patterns in a retail dataset
- **Dashboard design:** Organizing information into an accessible, business-focused reporting experience
